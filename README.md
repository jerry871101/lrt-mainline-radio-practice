# 淡海輕軌正線無線電練習

司機員與行控中心（OCC）之間「正線無線電報話」的練習網頁工具。
單一 HTML 檔、純前端，手機或電腦開網頁即可練習。

> 🌐 **線上練習頁**：<https://jerry871101.github.io/lrt-mainline-radio-practice/>
> （更新推送後約 1–2 分鐘自動生效）

## 功能特色

- **車站換端報話**：正線各站換端情境，含建議路徑號對照
- **故障排除情境**：牽引、煞車、列車操作（EB）、空調、ATP、車門、供電等 7 大類，隨機故障注入（站內/站間）
- **互動式 CMS HMI 模擬**：立體按壓觸感、5 節車廂（M1–M5）列車監控圖、總故障燈、380V 指示
- **其他情境**：勤務交接、備用車發車（1-0 / 2-0）、轉轍器手動扳轉、PEI 旅客對講機
- 逐句三段式報話（司機員回報 → OCC 指示 → 司機員複誦），一次展開一段

## 檔案導覽

| 檔案 | 內容 |
|------|------|
| `index.html` | 練習工具本體（單檔 SPA，HTML/CSS/JS） |
| `報話通用規則.md` | 跨情境報話慣例速查（發話權、結尾語、位置描述、收車流程等） |
| `MAINLINE_NOTES.md` | 正線 SOP 筆記 |
| `路線與路口代號圖.md` | 車站（V）與路口（J）代號對照 |
| `CONTEXT.md` | 開發脈絡與工作日誌（AI 協作用） |
| `工作日誌封存.md` | 已定稿情境的逐句紀錄封存 |

## 使用方式

直接開啟上方線上練習頁網址，或下載 `index.html` 用瀏覽器開啟（無需安裝任何東西）。
